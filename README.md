# Perceptron Lab

Интерактивный симулятор машинного обучения: пошаговый перцептрон, который
учится на простых данных прямо в браузере. Страница самодостаточна — весь HTML,
CSS и JavaScript находятся в одном файле `index.html`, без внешних зависимостей
и сетевых запросов.

## Живая страница

https://niiyazg.github.io/perceptron-lab/

## Что внутри

- Пошаговое обучение перцептрона: догадка → проверка → исправление → сдвиг линии.
- Наборы данных: «Простая», «Диагональ», «С шумом», XOR, И, ИЛИ.
- Режим Хебба и обучение по ошибке (дельта-правило).
- График ошибок по эпохам и таблица весов модели.
- Работает офлайн: достаточно открыть файл локально.

## Как открыть локально

Просто откройте `index.html` в браузере:

```
# из корня репозитория
start index.html        # Windows
open index.html         # macOS
xdg-open index.html     # Linux
```

Либо поднимите любой статический сервер, например:

```
python -m http.server 8000
# затем откройте http://localhost:8000/
```
